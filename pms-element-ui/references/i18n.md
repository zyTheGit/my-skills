# 国际化 i18n

> Element UI 多语言支持与自定义语言包

---

## 核心特性

- 内置多种语言包
- 支持自定义语言包
- 运行时动态切换

---

## 基础配置

### 引入语言包

```javascript
import Vue from 'vue'
import ElementUI from 'element-ui'
import locale from 'element-ui/lib/locale/lang/en'

Vue.use(ElementUI, { locale })
```

### 支持的语言

| 语言代码 | 语言名称 |
|----------|----------|
| zh-CN | 简体中文 |
| en | 英语 |
| zh-TW | 繁体中文 |
| es | 西班牙语 |
| fr | 法语 |
| de | 德语 |
| ja | 日语 |
| ko | 韩语 |
| ru | 俄语 |

## 自定义语言包

### 扩展现有语言包

```javascript
import lang from 'element-ui/lib/locale/lang/en'
import locale from 'element-ui/lib/locale'

// 添加自定义翻译
lang.myButton = 'My Button'

// 应用语言包
locale.use(lang)
```

### 完全自定义语言包

```javascript
const customLang = {
  el: {
    pagination: {
      goto: 'Go to',
      pagesize: '/page',
      total: 'Total {t}',
      pageClassifier: ''
    },
    table: {
      confirmFilter: 'Confirm',
      resetFilter: 'Reset',
      emptyText: 'No Data'
    }
  }
}

Vue.use(ElementUI, { locale: customLang })
```

---

## 动态切换语言

```javascript
// 切换语言
changeLanguage(langCode) {
  import(`element-ui/lib/locale/lang/${langCode}`).then(module => {
    locale.use(module.default)
  })
}
```

---

## 注意事项

- 语言包按需加载，减少初始包体积
- 自定义语言包需保留 `el` 命名空间
- 切换语言后 Vue 组件会自动更新
