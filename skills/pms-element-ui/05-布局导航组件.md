# 布局导航组件

> 10个布局导航组件，用于构建页面结构和导航

---

## 组件列表

| 组件 | 说明 | 常用场景 |
|-----|------|---------|
| Layout | 布局 | 页面整体布局 |
| Container | 布局容器 | 布局组合容器 |
| Breadcrumb | 面包屑 | 路径导航 |
| Dropdown | 下拉菜单 | 下拉菜单导航 |
| Menu | 菜单 | 导航菜单 |
| Tabs | 标签页 | 选项卡切换 |
| Steps | 步骤条 | 步骤导航 |
| PageHeader | 页头 | 页面头部 |
| Divider | 分割线 | 内容分隔 |
| Backtop | 回到顶部 | 页面滚动返回 |
