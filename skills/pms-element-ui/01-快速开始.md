# 快速开始

> 安装指南、快速上手、全局SDK使用说明

## 最小安装

```javascript
import Vue from 'vue';
import ElementUI from 'element-ui';
import 'element-ui/lib/theme-chalk/index.css';
Vue.use(ElementUI);
```

## SDK 30 秒速览

### window.$utils

```javascript
window.$utils.openTab({ appName: 'app-user', name: 'user-detail-123', path: '/app-user/detail/123', title: '用户详情' });
```

### window.$request

```javascript
const users = await window.$request.get({ url: '/users', params: { page: 1 } });
```

### window.$eventBus

```javascript
window.$eventBus.emit('message:fromApp', { appName: 'app-user', type: 'USER_UPDATED', data: { id: 123 } });
```

### window.$permission

```javascript
if (window.$permission.check('user:add')) { /* 显示添加按钮 */ }
```
