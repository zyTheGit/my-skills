# 反馈组件

> 11个反馈组件，用于用户操作反馈和提示

---

## 组件列表

| 组件 | 说明 | 常用场景 |
|-----|------|---------|
| Alert | 警告 | 警告提示 |
| Dialog | 对话框 | 模态对话框 |
| Drawer | 抽屉 | 侧边抽屉 |
| Loading | 加载 | 加载状态 |
| Message | 消息提示 | 全局消息 |
| MessageBox | 消息弹框 | 确认对话框 |
| Notification | 通知 | 通知提醒 |
| Popover | 气泡弹出框 | 气泡卡片 |
| Popconfirm | 气泡确认框 | 气泡确认 |
| Tooltip | 文字提示 | 悬浮提示 |
