# 主题色彩规范

> Element UI 主题色彩定义与使用说明

---

## 核心特性

- 预定义 5 种语义化主色
- 完整的中性色阶体系
- 四级边框颜色层级
- 支持 SCSS 变量自定义

---

## 主色规范

| 颜色 | 用途 | 默认值 |
|------|------|--------|
| Primary | 主要按钮、链接、选中态 | #409EFF |
| Success | 成功状态、完成操作 | #67C23A |
| Warning | 警告提示、注意操作 | #E6A23C |
| Danger | 危险操作、错误状态 | #F56C6C |
| Info | 信息提示、中性操作 | #909399 |

---

## 中性色规范

### 文字颜色

| 类型 | 用途 | 默认值 |
|------|------|--------|
| 主色 | 标题、重要文本 | #303133 |
| 常规色 | 正文、次要文本 | #606266 |
| 次要色 | 辅助说明、占位符 | #909399 |
| 占位色 | 禁用状态、空值提示 | #C0C4CC |

### 边框颜色

| 级别 | 用途 | 默认值 |
|------|------|--------|
| 一级边框 | 主要输入框、卡片边框 | #DCDFE6 |
| 二级边框 | 次级分隔线 | #E4E7ED |
| 三级边框 | 浅色分隔线 | #EBEEF5 |
| 四级边框 | 最浅背景边框 | #F2F6FC |

---

## 代码示例

```javascript
// 使用全局 SDK 获取主题色
const primaryColor = window.$config.theme.primary

// 动态设置 CSS 变量
document.documentElement.style.setProperty('--el-color-primary', '#409EFF')
```

```scss
// SCSS 变量引用
$--color-primary: #409EFF;
$--color-success: #67C23A;
$--color-warning: #E6A23C;
$--color-danger: #F56C6C;
$--color-info: #909399;
```

---

## 注意事项

- 主色应保持高对比度，确保可访问性
- 避免在深色背景上使用浅色文字
- 修改主色时需同步更新所有派生色
