# 基础业务组件

> 24个核心业务组件（23个 base-* + MicroKeepAliveView 微前端保活），提供企业级应用常用的高级功能

## 组件概览

| 组件名称 | 功能描述 | 应用场景 |
|---------|---------|---------|
| **BaseProTable** | 高级表格 | 列表页、数据展示 |
| **BaseProForm** | 高级表单 | 新增、编辑、查看详情 |
| **BaseProSearch** | 高级搜索 | 列表页搜索栏 |
| **BaseToolBar** | 工具栏 | 列表页头部、表格工具栏 |
| **BaseProProcess** | 流程查看 | 流程审批状态展示 |
| **BaseProcessHandle** | 流程处理 | 流程审批操作界面 |
| **BaseApprovalResult** | 审批结果卡片 | 审批结果展示，独立使用或嵌入表单 |
| **BaseOrgantCascader** | 组织机构选择 | 组织架构选择 |
| **BaseAffiliatedUnit** | 单位选择 | 所属单位选择 |
| **BaseDictionary** | 字典下拉 | 数据字典选择 |
| **BaseMapLocation** | 地图选点 | 百度地图位置选择 |
| **BaseWorkMap** | 五省地图 | ECharts 地图下钻、区划数据展示 |
| **BaseVirtualTree** | 虚拟树 | 大数据量树形展示（数千到数十万节点） |
| **BaseTree** | 树形控件 | 树形数据展示与操作 |
| **BaseImport** | Excel导入 | Excel文件导入 |
| **BaseChunkUpload** | 文件上传 | 图片/附件上传 |
| **BaseUploadList** | 文件列表 | 文件列表管理 |
| **BaseImgPreviewer** | 图片预览 | 图片查看预览 |
| **BaseFilePreviewer** | 文件预览 | 文档文件预览 |
| **BaseLayout** | 基础布局 | 应用整体布局框架 |
| **BaseIcon** | 基础图标 | 图标库与图标选择 |
| **BasePageFooter** | 底部操作栏 | 表单/详情页底部操作区 |
| **BaseViewSwitcher** | 视图切换 | card/table 视图切换 |
| **MicroKeepAliveView** | 微前端页签保活 | qiankun + 多页签场景下子应用页面缓存 |
